# Gerador TikTok Shop & Image-to-Video Google Veo 3 ⚡🎬

Aplicação web estática e responsiva para criação de roteiros de alta conversão para o **TikTok Shop** e geração de prompts técnicos **Image-to-Video (I2V)** para o **Google Veo 3** com protocolo rigoroso de trava no **Primeiro Quadro (Frame 0)**, DNA unificado de consistência entre cenas e orientações de conversão com **setas dinâmicas para o Carrinho Amarelo**, tudo em **100% Português**.

🔗 **Acesse Online:** [https://duhduh2019.github.io/Achadinhos_Jesus/](https://duhduh2019.github.io/Achadinhos_Jesus/)

---

## 🚀 Principais Funcionalidades da v1.4.0

### 1. Seletores 100% em Ordem Alfabética (A a Z)
Todos os campos e menus suspensos organizados alfabeticamente para navegação rápida e intuitiva:
- Nichos de Produto (Beleza ➔ Casa ➔ Infantil ➔ Moda ➔ Papelaria ➔ Pet ➔ Saúde ➔ Tecnologia)
- Ganchos Psicológicos (Achadinho Barato ➔ Anti-Hype ➔ Demonstração de Choque ➔ Dor Aguda)
- Gatilhos de Venda (Alerta de Estoque ➔ Frete Grátis ➔ Garantia ➔ Preço promocional)
- Estilos de Vídeo (Achadinho Viral ➔ Demonstração Prática ➔ Desboxing ➔ UGC Autêntico)
- Apresentador (Apenas as Mãos ➔ Pessoa Falando)
- Cinemática de Câmera (Aproximação Lenta ➔ Câmera Fixa ➔ Deslizamento Lateral ➔ Macro)
- Interação Física (Mãos Apoiando ➔ Micro-Ação ➔ Produto em Mesa)

### 2. Texto na Tela Implícito (Inteligência de Retenção)
- A IA define dinamicamente os letreiros mais chamativos para quem assiste no mudo (essencial para reter os primeiros 3 segundos no TikTok).

### 3. Chamada de Compra com Setas (`↘️ 👇`)
- Instruções visuais e gestuais no roteiro e na Cena 3 com stickers de setas animadas apontando diretamente para o botão do carrinho de compras no canto inferior esquerdo.

### 4. DNA de Consistência Unificado para Google Veo 3
- Todas as tomadas compartilham a mesma fórmula de iluminação de estúdio a 45° e bancada neutra, garantindo que o produto pareça gravado no mesmo local e sem alterações de cores entre clipes.
- Trava de Primeiro Quadro (Frame 0) mantida rigorosamente no topo de cada comando.
