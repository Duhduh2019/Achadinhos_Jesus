# Gerador TikTok Shop & Prompts Videos ⚡🎬

Aplicação web estática e responsiva para criação de roteiros de alta conversão para o **TikTok Shop**, geração de prompts técnicos **Image-to-Video (I2V)** para IAs de vídeo, e gerador de **Prompts de Alta Performance para IA criar Título + Hashtags em 1 Linha (Padrão TikTok)**.

🔗 **Acesse Online:** [https://duhduh2019.github.io/Achadinhos_Jesus/](https://duhduh2019.github.io/Achadinhos_Jesus/)

---

## 🚀 Principais Funcionalidades da v1.9.1

### 1. 🚫 Trava Zero Watermark & Clean Plate (Vídeo 100% Limpo)
- **Eliminação de Marca D'água:** Remove termos-gatilho (`"TikTok"`, `"TikTok Shop"`, `"botão de compra"`) dos prompts de IA de vídeo, prevenindo que difusores (Veo, Kling, Runway, Minimax) renderizem a marca d'água oficial ou logos nos frames.
- **Cláusula Mandatória Clean Plate:** Injeta proibição estrita de marcas d'água, logos, textos renderizados na imagem, legendas e elementos de interface/HUD nas tomadas geradas.
- **Separação Clara de Funções:** Deixa as chamadas de carrinho, vitrine e ganchos comerciais para o **Roteiro** e para a **Edição**, gerando tomadas visuais limpas e de qualidade profissional.

### 2. 🛍️ Modo Product Compilation (Top 3 Achadinhos do TikTok Shop)
- **Alternador de Modos:** Permite alternar instantaneamente entre o **Modo 1 (Produto Único)** e o **Modo 2 (Product Compilation - Top 3)**.
- **Roteiro de Alta Retenção (Listicle):** Estruturado no formato viral de 30-32s (00s-03s Gancho de Abertura, 03s-10s Item 1, 10s-18s Item 2, 18s-25s Item 3, 25s-30s Fechamento Coletivo direcionando para a **Vitrine do TikTok Shop** + Bordão de Marca).
- **Prompts I2V para Cada Produto da Lista:** Comandos individuais com Cláusula Frame 0, Trava Anti-Alucinação (Máx 2 Mãos) e Zero Marca D'água para você anexar a foto de cada um dos 3 itens na IA de vídeo.
- **Prompt para IA de Título & Hashtags em 1 Linha (Multi-Produtos):** Copy ultra-calibrada para o algoritmo do TikTok Shop indexar a lista, informando que os achadinhos estão disponíveis na Vitrine do perfil.
- **Prompts Fixos em 2 Passos Adaptativos:** O Storyboard UGC para o ChatGPT/Gemini adapta-se automaticamente para criar o planejamento visual dos 3 produtos de uma só vez com fechamento na Vitrine e instruções de vídeo limpo.
